# Scriptie_martijn

Supporting material for the thesis *Explainable Optimisation in Water Management using AI Agents*.

This repository contains the case study, the reference model used to check the answers, and the logged chat sessions. The software itself lives in two other repositories:

- [OptiChat](https://github.com/vumartijn/OptiChat): fork of OptiChat with the water-management adaptations and the three new tools.
- [rtc-tools](https://github.com/vumartijn/rtc-tools): fork of Deltares' RTC-Tools, with the original mixed-integer example.

## Contents

- `chats/`: the logged OptiChat sessions (chat histories) that were graded for the results in Chapter 5.
- `example_pyomo.py`: the case study as a Pyomo model.
- `stochastic_approximation.py`: the SPSA reference solution used to check the answers to Q7 and Q8 (Section 4.5).
- `figures/`: the figures used in the thesis.
